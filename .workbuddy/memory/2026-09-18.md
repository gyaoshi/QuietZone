5. **单元测试是空心的**：`test_feedforward_anc` 只断言 `frameCount>0`，且该用例 `secondaryPathLength=4 < 默认延迟 8` → Ŝ 全零 → 权重一次都没更新。测试且未接入 CI。

## v4 修复实施（同日续做，用户指令："修复你指出的这些问题，尽量实现一个好的效果；麦克风输入选一个麦就行"）

**算法架构（从"宽带反馈空转"改为物理可行的单麦方案）**
1. **宽带 FxLMS 反馈式（IMC）**：真实误差信号 `e = mic`；用估计扰动 `d̂ = e − Ŝ·y` 作参考，受回环延迟限制，有效带宽约 30–400Hz。
2. **窄带谐波抵消器（主力）**：内部合成参考 `A·cos(ωn+φ)/A·sin(ωn+φ)`（A∠φ = Ŝ 复数增益），每谐波复数权重 (wc,ws)，环路增益归一化到 1 → **对延迟免疫**，可覆盖风机/发动机等稳态噪声。
3. **次级路径 Ŝ 标定**：对数扫频探测 + 匹配滤波估 IR；稀疏化（峰值定位 + 0.2% 尾部截断 + 抽头上限 512）；无效标定（峰太弱/位置越界）直接拒绝并保留旧模型。
4. **步长规则**：`tonalStep = clamp(1.0/D, 2e-4, 2e-3)`（D=回环延迟采样数）；宽带 `mu = min(0.1, stepSize/(L·xh_pow))`。运行时发散守卫：NR 异常则减半步长+重置，累计 4 次后**禁用窄带支路**防啸叫。

**修掉的工程缺陷**
- `processCalibrationFrame(nullptr)` 死代码 → 校准真正接通；`calibrate()` 移出主线程（ViewModel/Service 用 IO 线程）。
- `start()` `running_` 竞态：`requestStart` 前置位。
- 双流漂移：弹性缓冲水位管理 + 时间规整（±1 采样滑移），修了 `fillMicBlock` **滑移方向反了** 的 bug（高水位应 +1 压缩 / 低水位 −1 拉伸）。
- 预热门从 40ms sleep 改为 20ms + 主动丢弃到目标水位（避免 8-block 环被灌满抬高回环延迟）。
- RT 回调去分配（扫描缓冲预分配 kMaxScanPoints=256）。
- `Usage::VoiceCommunication` 触发系统 AEC/NS/AGC 会毁掉误差信号 → 改 `Media` + `InputPreset::VoiceRecognition`（带降级 plan）。
- `secondaryPathLength` 1024→2048 覆盖共享模式缓冲延迟。
- Manifest 加 `FOREGROUND_SERVICE_MICROPHONE` + `foregroundServiceType="mediaPlayback|microphone"`。
